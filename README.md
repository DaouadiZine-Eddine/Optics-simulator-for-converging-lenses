# Optics-simulator-for-converging-lenses.
This project revolves around a simulator for converging lenses, it is able to represent light's trajectory through them in an accurate way using the law of thin lenses and optics. It offers for accuracy and efficicency. The simulator is also equipped with language settings for french and english.

# How to use it ?
Launch the launcher.py file after downloading the repository, then execute the python program and use it.
You will end up in an HTML website, depending on the langage you use and you can by scrolling down reach the simulator.
Enter the parameters you want, and you will be able to see the result.

The simulator therefore offers interesting insight on how light behaves, and a rather accurate simulation using the laws of Snell and Descartes, fulfilling both a usage for teaching and learning how to represent light.

# What are the limits of the simulator ?
The simulator can represent accurately light's behavior passing through a converging lens, even when the beam goes to infinity. It has very few limitations, and it is a project I adapted in order to give a good representation of phenomenons that include light. The only limitations may be that it only handles converging lenses, and not diverging ones nor treats advanced optics and catadioptric properties of mirrors, but I believe that representing them would be much better in a broader context with a much more specialized and advanced implementation using Python rather than HTML & Javascript.
